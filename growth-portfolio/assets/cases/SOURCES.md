캡처일: 2026.11.03. 브라우저에서 실제 공개 페이지와 UI를 확인한 뒤 저장했습니다. 이미지의 내용이나 숫자는 합성·변경하지 않았습니다.

## 아이원소프트뱅크

- `ione-before-product.png`: [기존 공개 ASP 제품 페이지](https://www.duzon119.co.kr/product/amaranth10/brand.asp). 메인포털 설명 옆에 일정 중심 이미지가 사용되는 화면. 2026년 9월의 보관 화면이 아닌 캡처일의 공개 페이지입니다.
- `ione-content-keywords.png`: [리뉴얼 제품 미리보기](https://soft-bank-beta.vercel.app/subpages/product/amaranth10/brand.html). 설명에 맞는 제품 화면, 관련 키워드, 확대 보기 버튼.
- `ione-product-zoom.png`: 같은 리뉴얼 제품 페이지의 메인포털 확대 보기 모달.
- `ione-product-bilingual.png`: 같은 리뉴얼 제품 페이지의 아마란스 10(Amaranth 10) 국·영문 병기.
- `ione-pms-zoom.png`: [리뉴얼 PMS 미리보기](https://soft-bank-beta.vercel.app/subpages/product/pms.html)의 대시보드 확대 보기 모달. 제품 화면 속 숫자는 포트폴리오 지원자의 사업 성과가 아닙니다.
- `ione-erp-diagnosis.png`: [ERP 가상 컨설팅 체크리스트](https://erptest-jet.vercel.app/)의 진입 화면.
- `ione-erp-question.png`: 같은 체크리스트의 첫 질문·진행률. 답변과 개인정보는 제출하지 않았습니다.

공개 미리보기는 HTML 페이지입니다. 사용자가 JSP(Java 서버페이지)를 사용했다고 직접 확인했습니다. ASP → JSP의 개발 경험은 이 설명으로 기재했으며, 이 캡처로 실제 서버 구현·배포 환경을 증명한다는 의미는 아닙니다.

성과 수치와 분석 경험은 사용자가 직접 제공했습니다. 비교 기간은 2026년 9월(개선 전)과 10월(개선 후), 문의·유입·재방문은 건수가 아닌 비율 지표의 증가입니다. 분석 출처는 GA4·Google Search Console·관리자 페이지 고객 DB입니다. 원본 분석 보고서나 고객 DB는 제공받거나 열람하지 않았습니다. 개별 기능의 인과 효과를 분리한 A/B 테스트 성과로 표현하지 않았습니다.

## 에어비앤비

- `airbnb-participation.png`: [기존 팀 캠페인 제안 PDF](https://eight-tau-19.vercel.app/assets/pdfs/lee-eungyu-airbnb-marketing.pdf) 8쪽을 고해상도로 렌더링한 이미지. 지역별 스토리 필터와 위치 맞히기·투표 콘텐츠 목업입니다. 이미지 속 반응 수와 투표 비율은 디자인 예시이며 실측 성과가 아닙니다.
- 캠페인의 대상·의도는 사용자의 최신 설명을 반영했습니다. ‘지금 어디에어’라는 콘셉트로 국토대장정 내·외국인 여행자의 위치 인증·공유를 주변 에어비앤비 숙소·체험 탐색과 이용 동기로 연결하는 기획입니다.

## 메타태그·키워드 근거 추가

- 2026.11.03 공개 리뉴얼 제품 페이지의 HTML을 읽어 title, description, keywords, og:type을 발췌했습니다. description은 앞부분만 표시했습니다. 개발자도구 캡처가 아닌 실제 소스 코드 발췌입니다. 컴퓨터 사용 도구가 현재 브라우저 URL을 확인하지 못해 개발자도구 캡처를 중단했습니다.
- 화면의 ‘#보안관리’와 제품 설명 영역은 기존 `ione-content-keywords.png` 캡처를 SVG viewBox로 확대 표시합니다. 원본 이미지 내용은 변경하지 않았습니다.
- BEFORE / AFTER는 같은 메인포털 설명을 비교합니다. 추가 기능의 과거 대응 화면을 확보한 것처럼 표현하지 않았습니다.
- [Google 공식 문서](https://developers.google.com/search/docs/crawling-indexing/special-tags)에 따라 meta keywords를 색인·순위 요소로 설명하지 않았습니다. 화면의 키워드·해시태그는 관련 기능을 이해하기 위한 정보 표시로 설명합니다.
