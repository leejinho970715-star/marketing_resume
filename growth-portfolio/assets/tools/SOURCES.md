# 광고 서비스 아이콘 출처

- `google-adsense.png`: [Google AdSense 공식 도움말](https://support.google.com/adsense/?hl=ko)에서 사용하는 [제품 아이콘](https://storage.googleapis.com/support-kms-prod/bJppRS0Z8FmVujFmM7KFHADzbq3L0PPb1Wpj).
- `kakao-adfit.png`: [카카오 애드핏 공식 사이트](https://adfit.kakao.com/info)의 스타일시트에서 사용하는 [제품 로고](https://t1.kakaocdn.net/biz/ui/adfit/main/logo_adfit3.png).
- `naver-adpost.png`: [네이버 애드포스트 공식 사이트](https://adpost.naver.com/)에서 사용하는 [네이버 로고](https://adpost.naver.com/logo_naver_v3.png). 옆에 서비스 이름을 함께 표시합니다.

Google AdSense·AdFit은 광고코드 삽입·게재·수익 지표 확인, 애드포스트는 미디어 등록·광고 노출 설정·보고서 확인으로 설명합니다.
