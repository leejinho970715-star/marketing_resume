# 광고 서비스 아이콘 출처

제품 식별을 위해 공식 서비스에서 제공하는 로고를 사용했습니다. 표시 크기만 조정했습니다.

- `google-ads.png`: [Google Ads 공식 도움말](https://support.google.com/google-ads/)에서 사용하는 [제품 로고](https://gstatic.com/ads/external/images/logo_google_ads_64px.png).
- `kakao-adfit.png`: [카카오 애드핏 공식 사이트](https://adfit.kakao.com/info)의 스타일시트에서 사용하는 [제품 로고](https://t1.kakaocdn.net/biz/ui/adfit/main/logo_adfit3.png).
- `naver-adpost.png`: [네이버 애드포스트 공식 사이트](https://adpost.naver.com/)에서 사용하는 [네이버 로고](https://adpost.naver.com/logo_naver_v3.png). 옆에 서비스 이름을 함께 표시합니다.

Google Ads는 광고주용 태그 적용·성과 보고서 확인, AdFit과 애드포스트는 매체의 광고 게재·수익 지표 확인으로 구분해 설명합니다.
